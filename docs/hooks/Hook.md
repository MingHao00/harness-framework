# Hook

**Hook（钩子）** 是一种 **拦截与扩展机制** ，它允许开发者在Agent执行流程的特定节点（如调用大模型前后、使用工具前后等）插入自定义逻辑，而无需修改Agent本身的核心代码。简单说，Hook就是在Agent的“生命旅程”中埋下的检查点，每当流程走到这些点时，就会触发你预先定义好的函数，完成后再回到正常轨道。


## 为什么需要Hook

一个自主Agent的典型运行流程是：接收任务 → 思考规划 → 调用工具 → 观察结果 → 再次思考 → 最终输出。如果所有逻辑都写死在核心循环里，想做日志、监控、权限控制或临时干预就会非常困难。Hook解决了这个问题：

* **解耦** ：核心行为（推理、执行）与横切关注点（日志、安全、缓存）分离。
* **可观测性** ：无需侵入代码就能记录每一步的输入、输出、耗时，便于调试和追踪。
* **动态扩展** ：可在运行时根据上下文动态修改Prompt、过滤工具结果，甚至中断危险动作。
* **复用的插件化** ：一个写好的Hook能在不同Agent间共享。
