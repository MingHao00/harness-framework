# Development Context

Mode: Active development
Focus: Implementation, coding, building features

## Behavior

- Prefer a working solution over a perfect one
- Order the work as working, then correct, then clean
- Run tests after changes
- Make atomic commits only when the user asked to commit
- Do not commit yourself

## Priorities

1. Get it working
2. Get it right
3. Get it clean
